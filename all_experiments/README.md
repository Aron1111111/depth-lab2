# 所有图像处理实验总览 / Обзор всех лабораторных работ

这个文件夹是在保留原有 `task1` 到 `task9`、`lab2` 的基础上新建的汇总任务，不会删除原文件。
Эта папка создана отдельно и не удаляет исходные `task1`–`task9` и `lab2`.

## 启动总览 UI / Запуск общего интерфейса

在项目根目录双击：
В корневой папке проекта запустите:

```powershell
all_experiments\run_all.bat
```

界面中可以点击 `TASK1` 到 `TASK9` 以及 `LAB2`，查看每个实验的图片、指标 JSON、文件列表和说明。
В интерфейсе можно открыть вкладки `TASK1`–`TASK9` и `LAB2`, посмотреть изображения, JSON-метрики, файлы и описание.

每个实验的原始代码和结果都复制在 `all_experiments/experiments/` 中；原目录仍然保留。
Исходный код и результаты скопированы в `all_experiments/experiments/`, исходные папки сохранены.
