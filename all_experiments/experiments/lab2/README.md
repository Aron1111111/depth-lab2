# Laboratory 2 — восстановление depth / 深度恢复

## 实验目标 / Цель работы

本实验的目标是恢复深度图中的缺失值，并且让实验结果可以被其他同学重复得到。
Цель работы — восстановить пропуски в depth-изображении и сделать эксперимент воспроизводимым для других студентов.

## 运行方法 / Запуск

在项目根目录执行：
В корневой папке проекта выполните:

```powershell
.venv\Scripts\python.exe lab2\restore_depth.py
```

也可以双击 `lab2/reproduce_all.bat`。结果保存在 `lab2/results/`。
Также можно запустить `lab2/reproduce_all.bat`. Результаты сохраняются в `lab2/results/`.

启动交互页面：
Для запуска интерактивного интерфейса:

```powershell
lab2\run_ui.bat
```

## 处理流程 / Процесс обработки

1. `valid = depth > 0`，生成有效性掩码。/ Создаём маску валидности: `valid = depth > 0`.
2. 使用 3×3 形态学闭运算处理小孔。/ Закрываем небольшие отверстия морфологическим оператором 3×3.
3. 使用带掩码统计的 Guided Filter 修复大孔洞，同时尽量保留边缘。/ Заполняем крупные отверстия Guided Filter с маскированием статистики и сохраняем границы.
4. 输出有效率、RMSE 和修复前后的图像。/ Сохраняем valid-процент, RMSE и изображения до/после.

## 文件说明 / Описание файлов

- `restore_depth.py`：批处理实验程序。/ Основной скрипт восстановления depth.
- `depth_lab_ui.py`：固定尺寸中俄双语交互页面。/ Фиксированный двуязычный интерфейс.
- `baseball_sample.png`：棒球视觉引导图。/ Изображение бейсбольного мяча для guidance.
- `config.json`：固定实验参数。/ Фиксированные параметры эксперимента.
- `data_card.yaml`：数据集说明卡。/ Паспорт датасета.
- `split_manifest.json`：固定评估划分说明。/ Описание фиксированного evaluation split.
- `CHECKLIST.md`：可复现性检查清单。/ Чек-лист воспроизводимости.
- `results/`：指标、掩码和处理前后图像。/ Метрики, маска и изображения до/после.

## 指标 / Метрики

实验记录有效深度像素比例、缺失区域 RMSE 和全图 RMSE。
Эксперимент записывает долю валидных depth-пикселей, RMSE на пропущенной области и RMSE по всему изображению.

## 可复现性 / Воспроизводимость

随机种子、图像尺寸、缺失率、孔洞位置和滤波半径都写在 `config.json` 中。
Random seed, размер изображения, доля пропусков, положения отверстий и радиус фильтра записаны в `config.json`.

依赖版本在 `requirements.txt` 中固定，完整检查见 `CHECKLIST.md`。
Точные версии зависимостей указаны в `requirements.txt`, полный чек-лист находится в `CHECKLIST.md`.
