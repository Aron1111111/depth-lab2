多传感器融合实验 / Sensor Fusion Lab
====================================

项目任务
--------
使用电脑自带摄像头作为真实视觉传感器，并模拟雷达、超声波输入，完成高层决策融合。
系统支持多数投票、加权融合和贝叶斯更新，适合展示“摄像头 + 雷达 + 超声波”的异构数据融合。

运行
----
双击 run.bat，或执行：

    D:\Anaconda\Anaconda\envs\yolov8_env\python.exe sensor_fusion.py

如果电脑没有可用摄像头，程序会自动切换到动态演示画面，界面和融合计算仍可操作。

项目说明
--------
1. 摄像头：读取实时画面，并用简单的边缘/运动特征判断是否存在候选目标。
2. 雷达：使用距离、速度、置信度滑块进行模拟。
3. 超声波：使用距离和置信度滑块进行模拟。
4. 多数投票：三个传感器中至少两个判断存在时，输出存在目标。
5. 加权融合：摄像头权重0.40，雷达权重0.40，超声波权重0.20。
6. 贝叶斯更新：从先验概率0.50开始，按摄像头、雷达、超声波的结果依次更新。

实验建议
--------
先把雷达距离设置为2.3m，超声波距离设置为0.9m，再改变摄像头画面、融合方法和置信度，观察最终结论变化。
可以保存当前帧和JSON实验记录，用于课程汇报。

答辩表述
--------
本项目采用高层决策融合。摄像头、雷达和超声波先分别输出“是否存在目标”和置信度，再在决策层合并。
这种方式不需要把像素、距离和声波原始数据强行放在同一个坐标系中，适合课程演示和传感器可靠性比较。
实际工程中若要得到真实雷达/超声波数据，需要连接对应硬件，并进行时间同步、坐标标定和误差建模。
